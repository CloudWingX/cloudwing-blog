## 关于本站

这里是 **云翼**（CloudWing）的个人博客，记录我在学习与折腾过程中的见闻与心得，内容涵盖前端开发、工具折腾与日常随笔。

站点基于 [Astro](https://astro.build) 静态站点框架，采用 [Firefly](https://github.com/CuteLeaf/Firefly) 主题模板搭建，并进行个性化定制。

## ✨ 特性

- ⚡ 基于 Astro 的静态站点生成，加载迅速、SEO 友好
- 🎨 现代化设计，支持亮色 / 暗色 / 跟随系统三种模式
- 📱 响应式布局，适配桌面端、平板与移动设备
- 🔍 基于 Pagefind 的全文搜索
- 🖼️ 相册、动态、友链、留言板等丰富功能模块

## 🚀 本地开发

### 环境要求

- Node.js ≥ 22
- pnpm ≥ 11

### 开始

```bash
# 克隆仓库
git clone https://github.com/CloudWingX/cloudwing-blog.git
cd cloudwing-blog

# 安装依赖
pnpm install

# 启动本地开发服务器
pnpm dev
```

开发服务器默认运行在 `http://localhost:4321`。

### 常用命令

| Command                    | Action                              |
| :------------------------- | :---------------------------------- |
| `pnpm dev`                 | 启动本地开发服务器                  |
| `pnpm build`               | 构建站点至 `./dist/`                |
| `pnpm preview`             | 本地预览已构建的站点                |
| `pnpm check`               | 检查代码中的错误                    |
| `pnpm format`              | 使用 Biome 格式化代码               |
| `pnpm new-post <filename>` | 创建新文章                          |
