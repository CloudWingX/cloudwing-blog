## About

This is the personal blog of **CloudWing**, documenting my journey of learning and tinkering, covering frontend development, tooling experiments, and daily musings.

The site is built with [Astro](https://astro.build), using the [Firefly](https://github.com/CuteLeaf/Firefly) theme template with personal customization.

## ✨ Features

- ⚡ Astro-powered static site generation — fast loading and SEO-friendly
- 🎨 Modern design with light / dark / system three modes
- 📱 Responsive layout for desktop, tablet, and mobile
- 🔍 Full-text search powered by Pagefind
- 🖼️ Rich modules including gallery, moments, friends, guestbook, and more

## 🚀 Local Development

### Requirements

- Node.js ≥ 22
- pnpm ≥ 11

### Getting Started

```bash
# Clone the repository
git clone https://github.com/CloudWingX/cloudwing-blog.git
cd cloudwing-blog

# Install dependencies
pnpm install

# Start the dev server
pnpm dev
```

The dev server runs at `http://localhost:4321` by default.

### Common Commands

| Command                    | Action                              |
| :------------------------- | :---------------------------------- |
| `pnpm dev`                 | Start the local dev server          |
| `pnpm build`               | Build the site to `./dist/`         |
| `pnpm preview`             | Preview the built site locally      |
| `pnpm check`               | Check the code for errors           |
| `pnpm format`              | Format the code using Biome         |
| `pnpm new-post <filename>` | Create a new post                   |
